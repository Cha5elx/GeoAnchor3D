## 意见 1

IGGA 使用的核心几何编码（欧氏距离，以及采用正弦/余弦编码的方位角和仰角）是三维点云处理和空间关系推理中已经成熟的技术，例如作者引用的文献 [5]。虽然将这些线索应用于逐头门控机制具有新意，但论文仍需更明确地讨论所提出的几何表示与已有工作的区别。具体而言，作者应说明是否考虑过可学习的空间嵌入（第五节对此有所提及），以及为什么优先采用手工设计的编码。手工几何特征与可学习空间嵌入之间的对比实验将有助于支撑这一设计选择。

### 回复 1

感谢审稿人的意见。距离和角度编码属于已有描述符；我们的贡献在于，以指令为条件，在物体注意力中逐头使用这些描述符。如第三节 B 小节所述，我们选择显式五维描述符，以提供紧凑、可解释的空间先验，同时保留可学习的相容性投影。这将几何量本身与其影响注意力的可学习方式区分开来。

当前实验考察的是使用该描述符时的几何路由，而非不同空间编码器之间的比较。我们并不声称手工特征优于可学习嵌入。这类对比将检验另一项表示设计选择，第五节已将其列为未来工作。

## 意见 2

整个框架依赖 Mask3D 生成的物体候选作为输入，作者也在第五节中承认了这一局限性。然而，论文没有定量分析候选质量如何影响下游性能。开展敏感性分析，例如改变候选数量（当前固定为 100），或在不同 Mask3D 置信度阈值下评估性能，将有助于读者理解 GeoAnchor3D 的鲁棒性边界。此外，涉及多物体场景的 Multi3DRefer 可能对候选漏检或合并尤其敏感，也应对此进行讨论。

### 回复 2

感谢审稿人指出候选敏感性问题。我们的比较考察的是：在给定相同检测物体的条件下，几何调控能否改善下游推理。因此，GeoAnchor3D 保留了 Chat-Scene 使用的每场景 100 个 Mask3D 候选。其收益是在预测候选而非真实标注的理想物体上评估的，不能归因于候选生成器的改进。

第五节现已说明，漏检、严重碎片化或合并的候选会限制下游推理。这对需要识别多个被指代物体的 Multi3DRefer 尤为相关。我们承认这一依赖；当前比较并未测量候选数量或置信度阈值的敏感性。

## 意见 3

作者强调 GATH 不引入推理开销，这是一个优点。然而，GATH 和 IGGA 的训练成本尚未得到量化。具体来说，应相对于基线，以训练时间或 GPU 显存占用的形式报告以下额外计算负担：（a）IGGA 中成对空间掩码的计算；（b）GATH 在多个 LLM 层上的水平与垂直聚合；（c）门控监督损失 Lgate。这些信息对于计算资源有限的研究者和开发者十分重要。

### 回复 3

感谢审稿人建议开展这一分析。第四节 C 小节新增的效率比较在单张 NVIDIA RTX 3090 上测试两个模型，批大小为 1，并使用 FlashAttention-2。每个样本的前向与反向计算时间从 547.87 ms 增加到 553.81 ms（+1.08%），训练时峰值已分配显存从 14.920 GiB 增加到 15.164 GiB（+1.63%）。这些测量不包含数据传输和优化器更新，因此不代表完整训练步骤或端到端训练的耗时。

这些结果量化了 IGGA、GATH 及辅助目标的总体开销，没有分别测量空间掩码计算、GATH 聚合或 $\mathcal{L}_{\mathrm{gate}}$ 的开销。推理时移除 GATH，而 IGGA 仍然运行。具体结果见题为“单张 NVIDIA RTX 3090 上的效率比较”的表格。

## 意见 4

所有实验都只使用 Vicuna-7B-v1.5 作为 LLM 主干。鉴于提出的模块（IGGA 和 GATH）被设计为不依赖特定主干，有必要验证其在不同 LLM 架构和规模上的有效性。至少应提供 LLaMA-2-7B 或 LLaMA-3-8B 的结果，以展示泛化能力。此外，论文还可增加更大 LLM（如 Vicuna-13B）的实验，研究分层空间调控带来的收益在更大模型上是否仍然存在或有所减弱，因为更大的模型可能本身就具有不同的模态整合行为。

### 回复 4

我们认同，测试其他 LLM 架构家族和规模，可以更直接地确定可迁移性的范围。在本文中，我们保留 Chat-Scene 的 Vicuna-7B-v1.5 主干，以在相同的物体中心框架内评估所提出的几何调控，避免在比较中引入主干变化。

当前结果支持该设置下的有效性，并未从实验上证明方法不依赖主干。第五节已将其他语言模型主干上的评估列为未来工作，我们的结论限定于已评估的框架和基准。

## 意见 5

相对于 Chat-Scene，性能提升虽然一致，但绝对幅度较小，例如 ScanRefer 的 Acc@0.25 提升 1.0%，Acc@0.5 提升 0.9%。论文没有报告多次运行的标准差或置信区间，因而难以判断这些收益是否具有统计显著性。考虑到使用 LoRA 微调 LLM 本身存在随机性，作者应至少报告三个随机种子下的均值和标准差。此外，论文还应讨论是否对 LoRA 秩（16）、学习率调度以及损失权重（$\lambda_{\mathrm{gate}}=1.0$、$\lambda_{\mathrm{coord}}=0.1$）进行了调优，并提供这些超参数的敏感性分析。
