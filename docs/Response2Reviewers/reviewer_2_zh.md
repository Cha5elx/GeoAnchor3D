# 审稿人 2：意见与回复（中文阅读版）

对应文件：`reviewer_2.tex`。以下按当前英文文件翻译，保留原有内容与数据；章节编号均指论文。第 1 条回复按要求保留的英文回答翻译。

## 意见 1

多头注意力的符号需要进一步澄清。当前 $\mathbf{A}_{\mathrm{sem}}$ 和 $\mathbf{A}_{\mathrm{fused}}$ 的公式没有显式包含注意力头维度，而门控系数却写为 $\alpha_h$。作者应对 $\mathbf{A}_{\mathrm{sem}}$、$\mathbf{M}_{\mathrm{spatial}}$ 和 $\mathbf{A}_{\mathrm{fused}}$ 使用一致的注意力头索引，并说明逐头计算、多头输出的聚合方式，以及 $\operatorname{Normalize}(\ast)$ 的准确定义，使数学表达与实现完全对应。

### 回复 1

感谢审稿人指出 IGGA 公式中的歧义。我们已经修订了符号，显式地为查询、键、值、语义注意力、融合注意力和输出表示添加注意力头索引。我们现在明确说明，几何相容性矩阵在各注意力头之间共享，而其作用由以指令为条件的逐头门控控制。我们还明确了几何调制后的归一化操作，并纠正了描述符定义中不一致的物体索引。这些修改使数学描述与实现保持一致，并明确了 IGGA 中的信息流。

## 意见 2

应澄清“指令感知”与“任务自适应”之间的关系。当前门控监督将任务类型作为先验。作者应进一步解释任务类型监督与由指令内容驱动的路由之间的关系。

### 回复 2

感谢审稿人建议澄清这一关系。“指令感知”描述的是门控的输入：通过池化后的指令嵌入预测各注意力头的系数。“任务自适应”描述的是这些系数针对不同任务需求的调控。训练时，任务标签提供软门控目标，而语言建模目标也会优化门控；两者是互补的监督来源。

第四节 C 小节新增的分析考察了这两方面的作用。移除 $\mathcal{L}_{\mathrm{gate}}$ 后，ScanRefer 的 Acc@0.5 从 51.1% 降至 50.9%。在 ScanRefer 内部，即使共享同一个任务先验，平均门控值仍随指令内容变化。这些发现支持“粗粒度任务先验与更细致的任务内变化相结合”的解释，而非门控路由独立于任务监督。详见“门控粒度与监督”和“任务内门控变化”两个段落。

## 意见 3

逐头设计的优势可以解释得更加清楚。表 3 显示可学习门控优于固定门控，但没有将逐头门控的贡献与共享标量门控的贡献区分开。

### 回复 3

感谢审稿人的建议。我们新增了由所有注意力头共享的可学习指令条件标量，并在所有变体中保留 GATH 和相同的四数据集训练方案。逐头门控将 ScanRefer 的 Acc@0.5 从 50.6% 提高到 51.1%，将 Multi3DRefer 的 F1@0.5 从 54.1% 提高到 54.6%，并将 ScanQA 的 CIDEr 从 88.6 提高到 89.9；Scan2Cap 的 CIDEr@0.5 保持为 77.2。由于两种门控均可学习且以指令为条件，该比较直接检验了注意力头粒度。

原门控设计消融仅在 ScanRefer 和 ScanQA 上训练，新增受控消融则在全部四个数据集上联合训练，这解释了两个表中参照结果的差异。应在各自相同的训练设置内比较不同变体。详见第四节 C 小节的“门控粒度与门控监督的受控消融实验”表。

## 意见 4

应更明确地说明与基础框架的关系。作者应澄清 GeoAnchor3D 建立在类似 Chat-Scene 的物体级表示框架之上，并更清楚地区分所提出的方法与静态融合方法。

### 回复 4

感谢审稿人的意见。第三节 A 小节现已明确列出沿用的 Chat-Scene 组件：以物体为中心的预处理、Mask3D 候选、物体标识符、Uni3D 和 DINOv2 特征，以及语言模型接口。IGGA 为物体间注意力增加了以指令为条件的几何调制，而 GATH 在训练期间对中间 LLM 表示施加坐标监督。与固定融合不同，IGGA 根据指令和注意力头调整几何调制。因此，本文贡献是在保留的物体中心框架内定义的。

## 意见 5

应适当限制结论的适用范围。当前评估主要集中在基于 ScanNet 的室内场景及相关任务。作者应避免将结论直接推广到开放世界、动态环境或不同的三维主干网络。

### 回复 5

我们认同结论必须与评估范围相符。修订后的引言和结论将实证发现限定于已评估的 ScanNet 室内基准。第五节明确区分了域内多任务适应与未见任务、跨域泛化，并将室外环境、动态场景和不同三维主干列为尚未测试的方向。
